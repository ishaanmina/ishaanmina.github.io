**IIT Delhi** · December 2022

Designed and 3D-printed a quadcopter from the frame up, including the test benches used to characterise it.

### Specifications

| Parameter              | Value   |
| :--------------------- | :------ |
| Total weight           | 211 g   |
| Rated payload capacity | 200 g   |
| Flight time            | ~30 min |

- Components: **ESP32** controller, 4× BLDC motors, 4× motor controllers, 3D-printed frame.
- Implemented a **PID control algorithm** for flight stabilisation, achieving stable hover and flight
  behaviour on the self-built platform.

### Skills

PID control design · ESP32 embedded programming · BLDC motor control · 3D printing and mechanical design · test bench design · systems integration
